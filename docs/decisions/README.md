# Decisions
This folder is a collection of Architecture Decision Records following the format proposed by Michael Nygard (2011). It is a log of decisions with reasoning and outcome.

## Format
- **Status**: Proposed, Accepted or Superseded
- **Context**: the situation or problem that made a decision necessary
- **Decision**: what was chosen, and why, among the alternatives considered
- **Consequences**: what changed as a result, good and bad
