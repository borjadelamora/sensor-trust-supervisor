# ADR-0001: Record architecture decisions

## Status
Accepted, 27/07/2026

## Context
To avoid losing track of decisions and to enhance reasoning, the Architecture Decision Records structure is adopted. Keeping such a record in the diary or in a plan file was considered, though ultimately ADRs provide a cleaner log of each choice such that intention doesn't get erased with time.

## Decision
An ADR will be added to this folder for each decision in the project that isn't straightforward.

## Consequences
This structure will be used from now on, with new entries added as the project progresses. Decisions will be better thought out, having undergone proper brainstorming.
